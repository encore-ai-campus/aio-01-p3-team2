# 오퐁 히어로즈 마을 원정 데모

`yejin` 운영 화면에서 생성하고 승인한 이벤트를 마을 원정 게임에 연결하는 로컬 플레이 데모다. 마을 건물과 자원을 관리하고, 병력을 훈련한 뒤 적 기지의 테두리 칸에 배치해 공격한다. 병력은 자동으로 이동·공격하며, 적 회관을 파괴하면 원정에서 승리한다.

## 실행

1. 승인된 이벤트를 연결하려면 백엔드를 실행한다. 이벤트 없이 마을과 원정을 체험할 수도 있다.
2. 이벤트를 연결할 경우 `yejin` 운영 화면에서 이벤트를 생성하고 규칙 검증·AI 검수 결과를 확인한 뒤 **운영 담당자 최종 승인**을 완료한다.
3. 저장소 루트에서 게임 서버를 실행한다.

```powershell
$env:BACKEND_BASE_URL="http://127.0.0.1:8000"
python demo-game/server.py
```

브라우저에서 `http://127.0.0.1:8090`을 연다. **이벤트** 메뉴에 승인된 `TASK-XXXXXXXXXXXX`를 입력하면 미션을 연결할 수 있다. `DEMO_GAME_PORT`로 게임 포트를 바꿀 수 있다. 게임 서버가 백엔드의 `GET /api/tasks/{task_id}`를 조회한다.

## 플레이

- 마을 건물을 클릭해 선택한다. 금화로 건물을 업그레이드할 수 있다. 채굴장은 15초마다 금화와 엘릭서를 수확한다.
- 훈련소에서 엘릭서를 써 병력을 추가한다. 훈련소 Lv.2부터 거인을 훈련할 수 있다.
- **적 기지 공격하기**를 누른 뒤 병력 종류를 고르고 지도 테두리의 밝은 칸을 클릭해 배치한다. 배치 뒤에는 병력이 자동으로 이동·공격한다. 방어탑은 가까운 병력을 공격한다. 회복 포션은 출정 병력을 회복한다.
- 적 회관을 파괴하면 금화·엘릭서·경험치·트로피를 얻는다. 마을로 돌아가 건물을 키우고 다음 원정을 준비한다.

## 이벤트 연결과 제한

- `workflow_status=COMPLETED`, `approval_status=APPROVED`, `critic_status=PASS`, `rule_validation.is_valid=true`인 Task의 `final_result`만 불러온다. 승인 대기·실패·거절·검증 실패 결과는 플레이할 수 없다.
- 승인 이벤트의 `monster_kill` 미션은 적 건물 파괴(`HUNT_001`), `dungeon_clear` 미션은 적 기지 점령, `level_reach` 미션은 대장 레벨 달성으로 데모에 연결한다. 일자별 미션을 완료하면 승인된 보상을 게임 안에서 지급한다.
- Clash 공개 표본 이벤트의 `building_destroy`, `raid_win`, `trophy_gain`은 각각 데모의 건물 파괴, 적 기지 점령, 가상 트로피 획득으로 진행한다. Clash API는 기획 시점의 상위 순위 표본에만 사용하며 게임의 적 기지나 이용자 계정과 연동하지 않는다. `DEMO_GOLD`, `DEMO_ELIXIR`, `DEMO_POTION` 보상은 이 데모의 자원이다.
- 마을 자원·건물·병력과 Task ID·결과 버전별 미션 진행은 브라우저 `localStorage`에만 저장한다. 출정 중 새로고침하면 진행 중인 전투는 복원되지 않는다.
- 실제 계정·인벤토리·보상 지급 API는 없다. 게임 진행은 백엔드에 기록되지 않는다. 개발용 로컬 서버이므로 외부에 공개하지 않는다.

테스트: `python -m unittest discover -s demo-game/tests -v`
