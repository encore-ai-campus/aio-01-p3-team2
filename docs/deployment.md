# 배포 문서 안내

이 문서는 저장소 루트에 남아 있는 초기 배포 문서 경로를 위한 안내다. 현재 배포 절차와 운영 상태는 아래의 IK 문서를 기준으로 확인한다.

- 현재 자원 상태와 검증 범위: [현재 구현 상태](ik/현재_구현상태.md)
- AWS 배포·운영 실행 절차: [AWS 배포 운영 실행 가이드](ik/기획안설계/26_AWS_배포운영_실행가이드.md)
- Actions 첫 배포 및 초기화 운영: [Actions 운영 가이드](ik/기획안설계/27_Actions_첫배포_초기화_운영.md)
- 날짜별 배포 검증 원본: [검증 산출물 색인](ik/검증산출물/README.md)

2026-10-13 최신 기록 기준 AWS 앱은 ABSENT이며 잔존 자원은 0이다. 과거 ACTIVE 배포와 수용 결과는 당시 실행 근거로 보존되어 있으므로 현재 운영 상태로 해석하지 않는다.
