# 오류 시나리오 문서 안내

이 문서는 저장소 루트의 초기 오류 시나리오 경로를 위한 안내다. 오류 분류·복구 정책의 설계와 실제 시험 결과를 구분해 확인한다.

- 오류 분류와 복구 정책: [오류 분류·복구 정책 설계](ik/기획안설계/05_오류분류_복구정책_설계.md)
- 오류 시험실 구현과 검증: [오류 시험실 구현·검증](ik/기획안설계/16_오류시험실_구현과_검증.md)
- 오류 주입 시험표: [오류 주입 시험표](ik/기획안설계/18_오류주입_시험표.md)
- 실행별 결과와 환경 제한: [검증 산출물 색인](ik/검증산출물/README.md)

설계 문서의 목표나 시험표의 시나리오 정의만으로 시험 완료를 의미하지 않는다. 실행 완료 여부는 날짜·환경·결과가 기록된 검증 원본에서 확인한다.
