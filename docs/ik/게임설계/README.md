# 가상 게임 세부 설계

이 폴더는 [가상 게임 도메인 상세 설계서](../가상게임_도메인_상세설계서.md)를 구현 가능한 수준으로 구체화하는 7개 하위 설계서 모음이다. 상위 문서가 정한 게임 경계·규칙 의미·논리 계약을 기준으로 하며, 충돌하는 결정이 필요하면 하위 문서에만 고정하지 않고 상위 문서의 결정 목록도 갱신한다.

## 사용 원칙

- 현재 구현과 목표 설계를 구분하고, 구현되지 않은 동작을 완료로 서술하지 않는다.
- 규칙과 사용자-visible 상태는 결정적으로 판정한다. 화면 연출은 서버 판정의 결과를 보여준다.
- `미결` 항목은 근거와 영향을 기록하고, 서로 다른 버전의 데이터를 섞지 않는다.
- 현재 코드에 존재하는 기능은 [현재 구현 상태](../현재_구현상태.md), 예정 파일·작업 순서는 [가상 게임 구현 계획](../가상게임_구현계획서.md)을 기준으로 구분한다. 계획의 기술·경로 선택을 구현 사실로 읽지 않는다.
- 이 문서들은 게임 도메인 설계다. 에이전트 Workflow·시스템 공통 보안·오류 복구·CI/CD 설계는 별도 시스템 설계서에서 다룬다.
