# AWS 배포 수명주기 구현 검증

기준: [운영 가이드 26](../기획안설계/26_AWS_배포운영_실행가이드.md).

## 확인한 사실

- Ruff/format, Python compile 및 IaC/계약 생성 일치 검사를 수행했다.
- 실제 계정에서 `bootstrap_oidc --apply` 성공. 공유 provider 재사용, 두 제어 IAM 역할과 비밀값 없는 GitHub 변수를 생성했다. OIDC subject는 저장소 실제 immutable ID + ikonly ref다.
- 새 status 검사로 앱 환경 ABSENT 및 잔존 항목 부재를 조회했다. RDS 자동 로그 누락 보정은 [정리 결과](2026-10-12_AWS_정리결과.md)를 따른다.
- 현재 앱 서버·DB를 새로 생성하지 않았다. 인증 연결 생성과 앱 운영 수용 성공을 구분한다.

## 아직 확인할 항목

GitHub 실제 OIDC 세션, 원격 Linux CI, 새 경로 첫 배포/선택 업데이트/전체 업데이트/실패 rollback/초기화 재실행. DB snapshot 자동 복원은 구현 범위에 포함하지 않았다. 코드 구현만으로 이 항목을 성공으로 기록하지 않는다.

## 원격 확인 완료

- [Linux CI 38217512944](https://github.com/ik-e/multi-agent-autohealing/actions/runs/38217512944): 코드·DB·UI·이미지/브라우저 연결·승인 gate 성공.
- [IaC CI 38217512788](https://github.com/ik-e/multi-agent-autohealing/actions/runs/38217512788): deterministic IaC·계약·CloudFormation 검사 성공.
- [OIDC 38217528679](https://github.com/ik-e/multi-agent-autohealing/actions/runs/38217528679): 실제 컨트롤러 assumed role 인증 및 ABSENT 앱 잔존 조회 성공. `IKONLY_CD_ENABLED=true` 활성화. AWS 장기 access key를 GitHub에 추가하지 않았다.
- AWS Access Analyzer 정책 검사: controller ERROR/WARNING 없음(중복 자원 SUGGESTION 한 건), CFN 역할 finding 없음.
- 첫 배포 CA 공개 인증서 로컬 export, 진행 중 stack 정착 대기, snapshot 소유 확인 및 삭제 재시도 보완.

## 초기화 후 자동 CD 시험

[CI/CD 38218237440](https://github.com/ik-e/multi-agent-autohealing/actions/runs/38218237440) 전체 성공. deploy job은 실제 OIDC 인증 후 `INACTIVE`, `created_resources=false`를 기록했다. 앱을 재생성하지 않는 계약을 실제 확인했다.

최초 로컬 이미지 다운로드는 원격 TCP 종료로 실패했고, 첫 배포는 artifact 검증 전에 중단되어 유료 앱 자원을 만들지 않았다. `download_artifact.py`는 8MiB 범위 4개 동시 다운로드, 5회 제한 재시도, 로컬 범위 이어받기와 GitHub ZIP digest 검사를 제공한다. signed URL/토큰은 출력·저장하지 않는다.
