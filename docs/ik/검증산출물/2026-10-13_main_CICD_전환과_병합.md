# main CI/CD·OIDC 전환과 병합

기준일: 2026-10-13 (Asia/Seoul). 사용자 승인: 문서 정리, main 실행 기준 전환, ikonly push, main 병합·push, 실제 main Actions 확인.

## 1. 변경 범위

- `.github/workflows/ikonly-ci.yml`, `ikonly-infrastructure.yml`, `ikonly-lifecycle.yml`의 push trigger와 실행 ref를 `main`으로 전환한다. 파일명은 기존 artifact provenance와 운영 명령 호환을 위해 유지한다. 표시 이름은 Main으로 바꾼다.
- 첫 배포의 검증 CI branch와 `publish_release.verify`의 완료/현재 run branch·ref 검사도 main으로 맞춘다. ikonly나 다른 브랜치의 성공 run으로 배포할 수 없다.
- `bootstrap_oidc.py`의 생성 subject와 실제 소유한 IAM controller 역할의 OIDC trust subject를 `refs/heads/main`으로 전환한다. 소유권 태그·계정·기존 aud/subject를 확인한 뒤 trust만 변경하고 재조회한다. IAM identity policy 및 공유 OIDC provider는 변경하지 않는다.
- 환경 이름 `ikonly-demo`, IAM 역할·Parameter 경로·GitHub 변수 이름은 유지한다. 자동 업데이트는 ACTIVE 환경만 대상으로 하며 첫 배포는 계속 수동이다.
- 기존 문서 정리 변경을 검토·포함하고 오래된 절 링크, IK 외부 미추적 참조, 최신 결과 우선순위, 원문 보존 정리 루프 설명을 보완한다. pre와 과거 실행 결과는 보존한다.

## 2. 이전 결정과의 관계

[문서 마무리](../문서_마무리와_루트_README_구성.md)는 당시 코드 변경 없이 마무리한 기록이다. 이번 사용자 요청은 CI/CD 브랜치 전환과 영향 검사를 추가로 승인한 후속 작업이다. [병합 전 점검](2026-10-13_main_병합전_전체점검.md)의 ikonly 고정·미커밋 상태는 전환 전 기록이다.

최신 통합·배포 기준은 main이며, 기존 ikonly branch/source의 시험은 당시 실행 증거로 유지한다. root README·로컬 clone·운영 가이드의 현행 진입점을 main으로 맞춘다.

## 3. 사전 검사·AWS 경계

AWS CLI는 계정 `042825953016`에서 유효한 인증을 확인했다. 별도 로그인 세션을 열지 않았다. 소유권 확인 후 `ikonly-control-controller`의 trust를 main으로 바꾸고 정확한 문서 일치를 재확인했다. 검증 자료는 Git 제외 `test-results/main-transition-2026-10-13/`에 보존한다.

이 전환은 앱 첫 배포 요청이 아니다. main Actions는 CI와 OIDC를 확인하고, 앱이 ABSENT이면 자동 CD는 INACTIVE로 종료해야 한다. 실제 Actions 결과는 아래 완료 기록에 추가한다. 이전 731 PASS를 새 main run의 결과로 표시하지 않는다.
