- 원본과 배포 출력은 Git 제외 `test-results/aws-first-current-2026-10-13/`, 이미지 후보는 `test-results/aws-current-candidate/`에 보관한다. 로그인 비밀번호·CA·환경 파일은 커밋하지 않는다.

## 확인할 완료 기준

1. 5 stack 및 6 서비스 생성, 정확한 source/image 배포와 역할별 readiness 통과.
2. private RDS TLS·일반/시험 DB 및 권한·실제 MCP/API 연결 통과.
3. 인증된 두 HTTPS 화면이 정상 표시되고 API·게임 저장 데이터와 연결됨.
4. 실제 OpenAI 기획 생성 → 사람 승인 → 선택 공간 게임 반영 → 진행/최초 보상 저장 및 중복 방지 확인.
5. 격리 복구 시연 샘플과 일반 데이터·정책 보존 확인.
6. 실제 결과·실패 및 보완 여부·접속 방법을 기록하고 라우터/현재 상태와 동기화.

게임 최초 화면은 자산 로드 전 빈 canvas가 잠시 보였다. network idle와 자산 로드 완료 후 로비·스테이지·던전·특별 공간 이미지, 영웅·몬스터를 확인했다. 최종 게임과 기획 폼의 asset 요청 실패·page error·console warning은 각각 0건이었다. 이는 서버 로그 전체가 무오류임을 뜻하지 않는다.

기계 판독 근거는 [검증 명세](2026-10-13_AWS_현행코드_첫배포_검증명세.json)다. 원본은 `test-results/aws-first-current-2026-10-13/`의 initial/fleet, live/, browser*.xml·console·Trace, database-proof.json, normal-preservation-after-fault.json, fault-status-final.json에 보존했다. 로컬 사본 시험 도구와 원시 자료는 커밋하지 않는다.

## 접속과 사용자 확인

- 기획안: **https://13.209.226.41/**
- 게임: **https://54.180.53.213/**
- 현재 접속 허용 IP: `222.100.72.176/32`. PC의 공인 IP가 바뀌면 허용 범위 갱신이 필요하다.
- Basic 로그인은 사용자 `operator`, 비밀번호는 로컬 `test-results/aws-first-current-2026-10-13/initial/web-login.txt`에서 확인한다. 기획안 내부 시연 로그인은 이후 별도 버튼이다.
- 현재 일반 게임에는 시험으로 만든 두 공간 이벤트가 적용돼 있고 미션 2/2가 완료돼 있다. 새로운 기획안을 생성·승인·등록해 다른 이벤트를 확인할 수 있다.
- 사용자 로컬 DB/MCP/Backend/두 프론트 서버는 종료하지 않았다.

Windows 신뢰 저장소에 **새 CA를 자동 등록하지 않았다**. Edge 최초 접속에서 인증서 경고 없이 사용하려면 아래 공개 인증서를 설치해야 한다. 해당 crt를 열어 인증서 설치 → 현재 사용자 → 모든 인증서를 다음 저장소에 저장 → 신뢰할 수 있는 루트 인증 기관을 선택하고, 아래 지문을 확인한 뒤 설치 경고를 승인한다. 이전 배포 CA와는 별개다.

## 유지 상태와 확인 한계

앱은 ACTIVE로 실행하며 자동 종료 시점은 지정하지 않았다. 실제 자원과 저장 데이터는 사용자가 전체 초기화를 요청할 때 [운영 가이드 26](../기획안설계/26_AWS_배포운영_실행가이드.md)의 reset으로 로컬 증거를 보존한 뒤 삭제한다. GitHub `IKONLY_CONFIG`의 접근 IP도 현재 값으로 갱신했다. 활성 환경은 ikonly push의 누적 서비스 변경을 역할별로 업데이트하는 기존 경로를 사용한다.

SNS 알림 메일 구독은 `PendingConfirmation`이다. 지정 이메일의 AWS 구독 확인을 완료해야 알림을 받을 수 있다. 이번에는 전체 장애 28개, 외부 OpenAI 장애, AWS rollback·snapshot 복원·전체 초기화 재시험을 수행하지 않았다. 기존 수명주기 검증과 이번 새 source의 첫 배포 수용을 구분한다.

기능을 차단한 배포 코드 오류는 이번 검증에서 발견하지 않았다. UI 표현 개선 대상으로 AWS인데 헤더가 `LOCAL RUNTIME`인 점, 긴 목표가 게임 이벤트 제목으로 표시되는 점, 최초 이미지 로딩 시 진행 표시가 없는 점을 기록한다. 이것을 해결한 코드로 배포됐다고 표현하지 않는다.
