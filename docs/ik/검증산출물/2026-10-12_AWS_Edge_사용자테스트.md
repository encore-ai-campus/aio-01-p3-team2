## 범위와 방법

실제 배포된 프론트엔드·API·RDS·MCP·OpenAI를 통한 일반 사용자 흐름이다. 기획안 입력·승인·게임 적용은 API 직접 호출 대신 화면으로 수행했다. 복구 시연은 별도 fault API/DB에서 실제 처리 코드와 결정적 LLM adapter를 사용했다. 이 두 오류 시험이 외부 OpenAI 장애 시험이라고 표현하지 않는다. 코드·배포 설정·일반 활성 정책은 수정하지 않았다.

## 발견한 UI 개선점

핵심 사용자 흐름을 차단하는 오류는 이번 범위에서 발견하지 않았다. 아래 항목은 표현 개선 대상이며 수정 완료 상태가 아니다.

1. **환경 표시:** AWS 화면의 헤더가 `LOCAL RUNTIME`으로 고정되어 배포 위치를 잘못 전달한다.
2. **운영 로그 상태 번역:** 정상 Supervisor 중간 상태·handoff의 REQUESTED/ACCEPTED 등이 `확인 필요`로 나타난다. 실제 작업은 정상 완료됐으며 상태 라벨 매핑을 보충해야 한다.
3. **언어 일관성:** 한국어 요청에서도 Critic 설명이 영어로 표시됐다. 처음 보는 사용자에게는 한국어 설명 또는 번역 계층이 필요하다.
4. **비동기 결과 구분:** 복구 시험 선택/새 실행 직후 이전 결과가 잠시 표시됐다가 새로운 기록으로 바뀐다. 선택한 오류와 표시 중인 결과가 다를 수 있는 짧은 구간에 조회 중/이전 결과 표식을 강화하면 좋다.

5. **이벤트 제목 길이:** 긴 기획 목표가 그대로 이벤트 제목에 쓰여 게임 오른쪽 카드에서 앞부분이 잘려 보인다. 짧은 이벤트 이름과 상세 목표를 분리하고 줄바꿈/말줄임 기준을 정리할 필요가 있다. 게임 완료 화면 증빙에서 확인했다.
