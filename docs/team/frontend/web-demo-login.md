# 운영 웹 프론트엔드 데모 로그인

`frontend-web`의 첫 화면은 내부 시연용 로그인 화면이다. 아이디 `liveops01`이 미리 입력되어 있으며, 비밀번호 없이 **로그인** 버튼을 누르면 **기획안 만들기** 화면으로 이동한다. 로그인 화면과 사이드바에는 방패 자리에 게임 캐릭터를 넣은 `frontend-web/public/event_quest_ai_logo_mascot_v3.png` 로고를 사용한다. 로고의 설명 문구는 "게임 속 퀘스트를 설계, 검토하는 AI"다.

로그인 여부는 현재 페이지가 열린 동안에만 메모리에 보관된다. 새 탭으로 열거나 새로고침하면 다시 로그인 화면이 나타난다. 상단 **로그아웃**을 누르면 로그인 화면으로 돌아가며 마지막으로 기억한 Workflow ID를 지운다.

이는 시연 화면의 진입 흐름만 구현한 것이다. 서버 인증이나 접근 제어를 제공하지 않으며, 실제 운영용 계정·비밀번호 처리로 사용해서는 안 된다. 기존 `docs/team/frontend/login.md`는 Streamlit 프론트엔드의 데모 로그인 설명이다.
