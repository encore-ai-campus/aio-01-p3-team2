# 테스트 시나리오 문서 안내

이 문서는 저장소 루트의 초기 테스트 시나리오 경로를 위한 안내다. 테스트 전략, CI 분류, 오류 주입 시나리오, 실제 실행 증거를 구분한다.

- 통합 검증 범위와 전략: [통합 검증 설계](ik/기획안설계/09_통합검증_설계.md)
- CI 테스트 분류: [CI 테스트 분류 정리](ik/기획안설계/22_CI_테스트분류_정리.md)
- 오류 주입 시나리오: [오류 주입 시험표](ik/기획안설계/18_오류주입_시험표.md)
- 실행 결과·환경·제한: [검증 산출물 색인](ik/검증산출물/README.md)
- 검증 구성 파일: [`infra/test-suites.json`](../infra/test-suites.json)

시나리오 정의와 CI 편성은 실행 증거가 아니다. 결과를 인용할 때에는 해당 검증 산출물에서 실행 시점, 대상 코드, 환경, 모집단과 제외 범위를 함께 확인한다.
